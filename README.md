# Doorlist QA

[Протокол прогона](https://dreddxyz.github.io/doorlist-qa/) · [Журнал сборок](https://github.com/dreddxyz/doorlist-qa/actions)

Два клиента одновременно покупают последний билет. Сколько заказов должно пройти? Проект содержит собственную мини-кассу на FastAPI/SQLite и три независимых набора тестов. Каждый прогон начинает с чистого локального сервера и временной базы.

| Контур | Что проверяем |
|---|---|
| pytest + HTTPX | Гонка за последнее место, идемпотентная бронь, повтор отмены, валидация количества |
| Playwright / Chromium | Бронь через форму, остаток, повторная попытка при исчерпании мест |
| Selenium / Firefox | Покупка двух билетов и сохранение остатка после обновления страницы |

Prefect оркестрирует проверки. GitHub Actions запускает их при push, вручную и ежедневно. Сохраняются JUnit XML, статус каждого теста, фактические длительности и SHA. Даже при падении теста в протокол попадает ошибка. Протокол публикуется на GitHub Pages.

## Запуск

Python 3.11, установленный Firefox и geckodriver (либо Selenium Manager), Chromium от Playwright.

```sh
pip install -r requirements.txt
python -m playwright install chromium
python run_checks.py
```

Для отдельного теста: `python -m pytest -v test_api.py::test_last_seat`. Для просмотра отчёта: `python -m http.server 8000 -d site`. Пример кассы служит тестовым стендом, запускается на loopback и использует вымышленные брони.

## Telegram

Бот читает опубликованный `receipt.json`. Команды `/latest`, `/checks`, `/links`. Облачный таймер Google Apps Script раз в минуту проверяет сообщения. Время ответа зависит от расписания и квот Google. Компьютер владельца в работе бота не участвует. Ссылка на отчёт есть в каждом результате.

Для собственной копии создайте Apps Script, скопируйте `bot/Code.gs`, сохраните токен отдельного бота как свойство скрипта `TELEGRAM_BOT_TOKEN`. Запустите `installDoorlist` один раз и разрешите внешние запросы и установку таймера. Скрипт проверяет, что у бота ещё нет webhook. Смещение Telegram хранится между запусками. Для остановки удалите триггер `pollDoorlist`. Источник отчёта задаётся константой в начале файла.
